Architecture & Connectivity

How should the application connect to the various sites?

A

Centralized Polling

One central server (Docker) polls all sites directly via SNMP. Requires VPN/Private Network connectivity to all site IPs.

B

Distributed (Per-Site)

A separate instance is deployed at each site. Good if sites are isolated, but harder to get a "global" view.

C

Hybrid / Agent-Based

Small SNMP agents at each site push data to a central dashboard. Best for unreliable links or many remote sites.
